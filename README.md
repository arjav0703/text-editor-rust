# Text Editor
This is a basic terminal-based text editor written in Rust 🦀.

## Usage 
- To run the text editor, use the following command in your terminal:
```bash
text-editor-rust <filename>
```

- Keybindings:
  - `Ctrl + Q`: Quit the editor
  - `Ctrl + S`: Save the file
  - Arrow Keys: Navigate through the text


## Installation (from source)
1. Make sure you have Rust installed. If not, you can install it from [here](https://www.rust-lang.org/tools/install).
2. Clone the repository:
```bash
git clone https://github.com/arjav07/text-editor-rust.git
```
3. Navigate to the project directory:
```bash
cd text-editor-rust
```

4. Build the project:
```bash
cargo build --release
```
5. Run the text editor:
```bash
./target/release/text-editor-rust <filename>
```
